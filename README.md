# Startup: Creative Agency Landing Page
A responsive landing page template for a creative agency, built as a test project to demonstrate Frontend development skills.

---

## 🚀 Technologies Used
* **Pug**: A template engine that simplifies writing HTML.
* **Sass (SCSS)**: CSS pre-processor for more efficient styling.
* **SVG & WebP/JPG** – Optimized assets for modern browsers.
* **JavaScript (vanilla)**: All interactivity is built with pure JavaScript, without any frameworks, to demonstrate core language skills.
* **Gulp**: An older task runner used for automating the build and compilation process.

---

## ✨ Features
* **Responsive Navigation**: A mobile-friendly hamburger menu for easy access.
* **Parallax Backgrounds**: A dynamic visual effect for an immersive feel.
* **User Authentication**: Pop-up forms for Sign Up and Sign In with input validation using regular expressions.
* **Smooth Content Transitions**: Sections appear as you scroll down the page.
* **Dynamic Carousel**: A looped carousel for testimonials that works with both clicks and swipes.
* **Filterable Works Section**: Project cards can be filtered by category, which is saved in Local Storage.
* **Timed Slider**: An automated slider with active markers for client logos.

## 💻 How to Run Locally
### Option 1: View the Live Demo
This project can be viewed directly using `GitHub Pages` or by simply opening the `index.html` file from `docs` folder in your browser.

### Option 2: Explore the Code & Build Process
1.  Clone the repository:
    ```bash
    git clone https://github.com/Mr-No-bo-dy/StartUp.git
    ```

2.  Navigate to the project directory:
    ```bash
    cd StartUp
    ```

3.  Install the dependencies:
    ```bash
    npm install
    ```

4.  Run the Gulp task runner:
    ```bash
    gulp
    ```
    This command will compile the Pug and Sass files, watch for changes, and start a local development server.
